# 2048 小游戏

一个使用原生 HTML、CSS 和 JavaScript 编写的 2048 网页小游戏，不需要安装依赖或构建工具。

## 运行

直接双击打开 `index.html`，或在项目目录启动任意静态文件服务器后访问页面。

## 操作

- 使用键盘方向键或 `W` `A` `S` `D` 移动方块。
- 在手机或触摸屏上滑动棋盘。
- 小屏设备也可以使用棋盘下方的方向按钮。
- 点击“新游戏”重新开始。游戏结束或合成 2048 后，点击提示层即可再来一局。

## 规则

相同数字相撞时会合并为它们的和。每次有效移动后，棋盘会在空位随机生成一个 2 或 4。棋盘没有空位且无法继续合并时游戏结束。

最高分会保存在浏览器的 `localStorage` 中，因此刷新页面后仍会保留。

## 文件说明

- `index.html`：页面结构和可访问性标记
- `styles.css`：响应式布局和数字方块样式
- `app.js`：棋盘状态、移动合并、分数、触摸和键盘交互
